# Ninja Roll 🥷
2D endless-runner-inspired obstacle avoidance game

# Gameplay
- Control the blue ninja (WASD) to dodge red ninjas and red blocks coming from the right!
- Press the space bar to shoot shurikens to defeat red ninjas
- Score higher for surviving longer!

# Technical
- Created with Greenfoot
- Features original sprite designs
- Uses right-to-left object movement, periodic enemy spawning
